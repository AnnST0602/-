# Сайт группы МУЗ СОЮЗ

Одностраничный сайт без сборки: всё в `index.html`. Открывается в браузере как есть, подходит для GitHub Pages.

## Что заполнить

1. **Контакты и ссылки** — блок `CONFIG` в конце `index.html`: номер WhatsApp, телефон, почта, соцсети. Все кнопки «Узнать цену» сразу начнут вести в WhatsApp с готовым текстом.
2. **Фото** — найдите в коде комментарии `ЗАМЕНИТЬ`. Заглушку `<div class="ph" ...>...</div>` замените на `<div class="ph"><img src="img/имя.jpg" alt="..."></div>`.
3. **Видео** — в `data-src` у кнопок видео вставьте ссылку для встраивания (YouTube `https://www.youtube.com/embed/ID`, VK Видео, Rutube).
4. **Тексты** — о группе, цифры, состав, жанры, афиша, отзывы.
