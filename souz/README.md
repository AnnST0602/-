# Сайт группы МУЗ СОЮЗ

Одностраничный сайт без сборки: `index.html` + папка `img/`. Открывается в браузере как есть, подходит для GitHub Pages или любого хостинга.

## Как устроено

- **Контакты** — константа `CONTACT` в скрипте внизу `index.html` (телефон Тимура и почта). Кнопки WhatsApp / Telegram / MAX и форма заявки берут данные оттуда.
- **Форма заявки** — город, дата, имя, телефон, комментарий. Без сервера: собирает текст и открывает WhatsApp, Telegram (текст копируется в буфер) или почту. Для автоматической отправки можно подключить Telegram-бота или сервис форм.
- **Видео** — карусель Rutube, id роликов в атрибутах `data-id`.
- **Фото** — `img/`, обработка в тёплую сепию через класс `.photo`.
- `blue.html` — прежний синий вариант дизайна.

## Чего ждём от группы

Ссылку на старое промо, логотипы клиентов, ссылку на разбор блогера, файл репертуара, скриншоты отзывов из сторис.
